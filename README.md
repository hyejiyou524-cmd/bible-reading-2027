# 📖 성경통독(연대기) 2027 — 365일 1년 1독 · 원어 · 묵상

`index.html` **파일 하나**로 완전히 동작하는 성경통독 컴패니언입니다. 외부 라이브러리·폰트 CDN·서버·인터넷 연결이 필요 없습니다.

통독표는 **The Bible Recap 365-Day Chronological Reading Plan**(thebiblerecap.com 공식 Full Reading Plan)을 따릅니다. 사건이 일어난 순서대로 읽는 1년이며, Day 273 말라기로 구약이 끝나고 **400년의 침묵기** 뒤 **Day 274에서 신약(누가복음 1장·요한복음 1장)이 시작**됩니다.

## 여는 법
- **아이폰**: 파일 앱에서 `index.html`을 길게 눌러 → 공유 → Safari로 열기. 열린 화면에서 공유 → "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다.
- **데스크톱**: 파일을 더블클릭하면 브라우저에서 바로 열립니다.
- 주소 끝에 `#day=274` 처럼 붙이면 그 날짜로 바로 열립니다(북마크용).

## 들어 있는 것
| 화면 | 내용 |
|---|---|
| **오늘** | 읽기 범위, 읽기 완료 체크, 그날의 시대 표시, 핵심 해설, 원어 포인트(원어 표기·발음·음역·뜻·뉘앙스), 묵상 질문 2개, 나만의 묵상 메모(자동 저장) |
| **통독표** | 연대기 흐름 바(구약 273일 · 신약 92일), 9개 시대 탭, 1~12월 탭, 월별 달력(읽은 날 표시) + 365일 목록, 눌러서 바로 이동 |
| **내 묵상** | 작성한 묵상만 모아 보기, JSON/텍스트 내보내기, 클립보드 복사 |
| 상단 대시보드 | 완료 일수·퍼센트·연속 통독일·남은 날, 다크 모드 토글 |

- **Day 1~365 전 날**에 해설·원어 카드 2개·묵상 질문 2개가 들어 있습니다. 비어 있는 날이 없습니다.
- **원어 표기 언어**: 구약(Day 1–273)은 히브리어, 다니엘 4~7장처럼 아람어로 기록된 구절은 아람어로 표시하고 카드 라벨도 `원어 포인트 · 히브리어` / `· 아람어`로 바뀝니다. **신약(Day 274–365)은 헬라어**로 표시되며, 카드 라벨이 `원어 포인트 · 헬라어`, 원어 글자는 왼쪽에서 오른쪽으로 읽도록 렌더됩니다.
- 통독표는 **성경 66권 1,189장 전체**를 365일에 빠짐없이, 겹침 없이 배분했습니다. 하루 1~8장이며, 시편은 여러 편이 흩어져 들어가는 날이 있습니다(예: Day 106 `시편 56, 120, 140–142편`).
- 여러 책이 섞인 날은 `신명기 32–34장; 시편 91편`, `사무엘하 5장; 역대상 11–12장`처럼 그대로 표기합니다.
- 시대 구분: 창조와 족장(1–29) · 출애굽과 광야(30–81) · 가나안 정복과 사사(82–97) · 왕정의 시작·다윗(98–147) · 솔로몬과 지혜서(148–182) · 예언자들의 시대(183–238) · 포로와 귀환(239–273) · 신약·예수님의 생애(274–319) · 초대 교회와 서신(320–365).
- 성경 본문은 수록하지 않았습니다. 본인의 성경책이나 성경 앱으로 본문을 읽으며 해설·원어·묵상과 함께 보는 컴패니언입니다.
- 기록은 이 기기의 브라우저 저장소(`localStorage`, 키 `br2027:tbr:v2:state`)에만 남습니다. 서버로 아무것도 보내지 않으며, 기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로 **내 묵상 → JSON 저장**으로 백업해 두세요.

## 다시 빌드하기
```bash
cd build && python3 build.py     # build/content_*.json + plan_data.json + template.html → ../index.html
cd build && python3 verify.py    # Chromium으로 365일 전수 렌더·원어 언어·다크모드·내보내기 검증
```

## 폴더 구성
```
index.html            완성본 (이 파일만 있으면 동작)
preview/              화면 미리보기 이미지 (verify.py가 생성)
build/
  plan_source.json    thebiblerecap.com 공식 PDF에서 뽑은 365일 원본 (영문 약어 + 장 목록)
  build_data.py       plan_source.json → plan_data.json (한국어 표기·날짜·시대, 1,189장 무결성 검사)
  plan_data.json      생성된 365일 통독표
  content_jan.json    Day 1~31   해설·원어·묵상 질문
  content_02_04.json  Day 32~120
  content_05_07.json  Day 121~212
  content_08_09.json  Day 213~273
  content_10_12.json  Day 274~365 (신약 · 헬라어 원어)
  template.html       화면·스타일·스크립트 원본
  build.py            위 재료 → index.html (합계 365일 · 중복/누락 검사)
  verify.py           실제 브라우저 검증 스크립트 (Playwright/Chromium)
```

## 해설 데이터 형식
`build/content_*.json`은 아래 형식의 배열입니다. `d`(Day)만 다르면 되고, `build.py`가 Day 1~365를 빠짐없이 한 번씩 합칩니다(중복·누락 시 빌드 중단).

```json
[{ "d": 32, "title": "제목", "key": "출애굽기 7:5",
   "summary": "3~5문장 해설",
   "words": [{"he":"...", "kr":"발음", "tr":"음역", "mean":"뜻", "note":"뉘앙스 설명"}],
   "q": ["질문1", "질문2"] }]
```
